# laravel-engineering

Cross-cutting implementation discipline for Laravel changes: context tracing, reuse, readable code, explicit failures, consumer-ready reads and critical-path verification.

8 rules. Baseline: Laravel `^12.0 || ^13.0`, PHP `^8.3`.

## Install

```bash
npx skills add Foysal50x/skills --skill laravel-engineering
```

Or as part of the Claude Code plugin:

```
/plugin marketplace add Foysal50x/skills
/plugin install laravel-skill@foysal50x
```

## Contents

- `SKILL.md` — routing and the implementation protocol
- `rules/` — focused context, design, correctness and verification rules
- `AGENTS.md` — every rule compiled into one document (generated)

See the [repository README](../../README.md) for the complete skill set.
