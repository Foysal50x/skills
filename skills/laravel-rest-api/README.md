# laravel-rest-api

The HTTP edge: authorization, Form Requests and DTOs, scoped route model binding, API Resources, and exception-to-status mapping.

31 rules. Baseline: Laravel `^12.0 || ^13.0`, PHP `^8.3`.

## Install

```bash
npx skills add Foysal50x/skills --skill laravel-rest-api
```

Or as part of the Claude Code plugin:

```
/plugin marketplace add Foysal50x/skills
/plugin install laravel-skill@foysal50x
```

## Contents

- `SKILL.md` — sections, the full rule list, and when to apply them
- `rules/` — one file per rule, with an incorrect and a correct example
- `references/` — deep dives and a pre-merge checklist, read on demand
- `AGENTS.md` — every rule compiled into one document (generated)

See the [repository README](../../README.md) for the full skill set.
